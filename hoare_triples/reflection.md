# Триплы Хоара

**Триплы Хоара** представляют из себя тройку условий, которыми можно формализовать корректность кода:

## $\left\lbrace P\right\rbrace C\left\lbrace Q\right\rbrace$

P - Precondition
C - Command
Q - Postcondition

Условия гласят, что если при условии P, после исполнения C, выходит Q - значит код корректен, например:

```go
// P: x = n
// C: Inc(x)
// Q: x = n + 1
func Inc(x int) int {
	return x + 1
}
```

То есть существует `x`, который изначально равен `n`, если после исполнения команды, значение `x` станет на 1 больше, значит код корректен.

Проверяются такие условия посредством тестирвоания.

## Использования с циклами

С циклами **Трипл Хоара** играет роль на каждой итерации, за счет выполнения логического условия - инварианта цикла.

**Инвариант цикла (I)**- это логическое утверждение, которое остается истинным для каждой итерации цикла.

И вместе с инвариантом - **Тройка Хоара** работает следующем образом, если инвариант истинен до начала цикла, тогда он должен быть истенен и на каждой его итерации, тогда при завершении цикла, инвариант вместе с условием завершения цикла будет обеспечивать выполнение постусловия.

Инвариант описывает состояние программы, которое не меняется с каждой итерацией, беспрерывно подтверждая правильное выполнение задач программой на каждой итерации.

Функция факториала:

```go
// P: res = 1
// C: factorial(n)
// Q: res = n!
func factorial(n int) int {
	result := 1
	for i := 1; i <= n; i++ {
		result = result * i
	}

	return result
}
// I: 0 <= i <= n & res = i!
```

После каждой итерации, `result = i!`, соответсвенно по индукции после цикла, `result = n!`

Доказательство:

1. Инициализация
   До цикла, `i = 1, res = 1`, проверим наш инвариант: `0 <= 1 <= n & res = 1! = 1`, все корректно

2. Сохранение инварианта:
   Тогда предположим, что наш инвариант истинен лишь до некоторой итерации, где `1 <= i <= n & res = i!`

В цикле:

```
i = i + 1
res = res * i
```

Тогда после итерации получаем:

```
i = i + 1 -> res = (i - 1)!
res = (i - 1)! * i = i!
```

Доказали коректность, инвариант по прежнему истинен.

3. Завершение
   При окончании цикла, `i = n`, тогда `res = i! = n!`, следовательно постусловие выполнилось

## Примеры

В примере нам необходимо с помощью **Трипла Хоара** показать корректность кода

```go
package hoaretriples

// P: a = n, b = m, result = True
// C: max(a, b)
// Q: (result = a || result = b ) && (result >= a && result >= b)
func max(a, b int) int {
	if a > b {
		return a
	}

	return b
}

// P: true
// C: abs(x)
// Q: result = |x|
func abs(x int) int {
	if x < 0 {
		return -x
	}

	return x
}

// P: True
// C: MaxOfAbs(a, b)
// Q: max(|a|, |b|)
func MaxOfAbs(a, b int) int {
	return max(abs(a), abs(b))
}

```

`max(a, b)`:

- если `a > b`, то результат будет равен `a`, что подходит под наше постусловие
- если `a <= b`, то результат будет равен `b`, что также подходит под наше постусловие
  Следовательно можно говорить, что функция корректна

`abs(a)`:

- если `a < 0`, то результат будет равен `-a`, что подходит под наше постусловие
- если `a >= 0`, то результат будет равен `a`, что подходит под наше постусловие
  Следовательно можно говорить, что функция корректна

`MaxOfAbs(a, b)`:

- Доказывается корректность тем, что все другие триплы функций, также корректны - по индукции
